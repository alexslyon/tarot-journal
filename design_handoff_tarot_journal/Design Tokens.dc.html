Type

Newsreader for written things, Inter for the instrument.
{{ t.sample }} {{ t.name }} {{ t.size }}
Deviation 1 of 3
A serif the system does not have

Nocturne sets everything in Inter. Entry titles, panel headings and card names here take Newsreader at weight 300.

The reason is the artefact: a journal entry is a written object that has to survive being printed, and the serif is what makes the screen and the page the same document. Inter keeps every interface role — controls, labels, data, metadata — so the split is legible rather than decorative.

--tj-font-display / --tj-font-ui

Deviation 2 of 3
14px, not the system's 8

Nocturne bakes an 8px radius. Cards and panels here run 14px, and controls go fully round.

A tarot card has a physical corner; at the size the app shows one, 8px reads as a clipped rectangle. Panels then match the card so nothing looks cut from a different sheet. Rows stay at 10px — they are list items, not objects.

--tj-radius-card / -panel / -row

Deviation 3 of 3
A light ground in a dark system

Nocturne is a dark system. The printed entry sets on --tj-paper (neutral-100) with ink from the dark steps.

Nothing else in the app inverts. This is the same palette read from the other end — no second theme, no new hues, and one accent step (700) survives into ink so a printed entry is still recognisably the app's.

--tj-paper-*
